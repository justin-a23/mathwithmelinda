## Mistakes I made — know these

**I broke production this morning.** Removing the hardcoded `APPSYNC_API_KEY`
fallback was right, but Amplify Console env vars are NOT available to the
Next.js SSR runtime — only to the build. Every server route touching AppSync
500'd until `amplify.yml` was changed to write them into `.env.production`.
That is what made Justin's year-end run delete two students' Cognito logins and
fail to archive their profiles. Fixed; profiles archived; ordering reversed so
a failure can no longer do that.

**Lesson 7 had two math errors** that survived my own review — a wrong answer
key (Q10) and a word problem yielding half a person (Q13). Both found by
recomputing, not re-reading. Recompute answer keys; do not trust them.

**My first Gen 2 schema draft used `allow.group('student')`** — and that group
has zero members, so every student would have been denied everything. Verify
auth rules against the live Cognito pool, not against what the code implies.

## Gotchas worth knowing

- **`npm audit` reports ~60 high.** They are Next's own nested `sharp` and
  `postcss`. Not reachable: the app renders submissions with plain `<img>` and
  presigned URLs and uses `next/image` nowhere. Do not "fix" by downgrading Next.
- **`npm ci` will fail.** This repo deliberately does not maintain a synced
  lockfile; both build phases do `rm -rf node_modules package-lock.json && npm
  install`. Build #285 failed because I ignored that.
- **`amplify_outputs.json` is gitignored** and holds the API key. Regenerate
  with `npx ampx generate outputs --branch main --app-id dg6hiwssnna5c`.
- **Node 22 needs explicit `.ts` extensions** in `amplify/backend.ts` imports.
- **`verify-gen2-migration.mjs` and the migration script accept
  `GEN2_TEACHER_TOKEN`** — use a teacher Cognito token rather than temporarily
  granting the API key access.
- The classifier blocks `amplify push`, `cdk bootstrap`, and deployment-config
  changes. Those need a permission rule or the user.
